# 内陆线国道平行绕行二次审查设计

## 目标与当前基线

- 目标是在不破坏 15 个骑行日可行性的前提下，优先绕开连续较长或风险较高的国道路段。
- 当前内陆线约 1816.6 km，相对逐段直接路线多 7.9%，其中已识别国道约 230.2 km。
- 全程绕行上限按基准路线的 15% 控制，不要求每个城市间路段单独满足 15%。
- 不以“国道里程归零”为目标；短距离穿越和接驳若没有明显风险，可以保留。

## 审查优先级

### P0：必须重点寻找替代线

满足任一条件：

- 连续国道路段不少于 20 km；
- 存在大货车、港区、快速路出入口、长桥、长隧道或无安全骑行空间等明显风险；
- 即使里程较短，但现场风险可能造成无法安全通行。

当前首批 P0 路段：

1. 信丰 → 龙南：约 43.2 km 国道；
2. 南城 → 广昌：约 39.2 km 国道；
3. 和平 → 河源：约 34.3 km 国道；
4. 上饶 → 鹰潭：约 25.9 km 国道；
5. 定南 → 和平：约 25.7 km 国道。

### P1：额度允许时优化

- 连续国道路段为 5–20 km；
- 有明确、连续且补给条件不差的平行省道、县道、旅游公路或城市道路候选。

### P2：默认保留

- 少于 5 km 的城市出入、穿越或接驳路段；
- 除非发现 P0 中定义的硬风险，否则不为其消耗额外 API 调用。

### 景观道路例外

翁金线等顺路、连续、适合骑行且有内容价值的道路，可作为景观优化候选，即使当前路径没有明显国道路段。景观候选不得以进入偏僻、失修或补给不足道路为代价。

## 候选生成与比较

1. 先用政府、交通部门及可靠地方资料确认道路名称、连续性、道路属性和已知施工情况。
2. API 额度恢复后，对 P0 逐段加入少量关键锚点，生成平行省道、县道、旅游道路或城市道路候选。
3. 每次只增加能改变走廊选择的锚点；所有响应继续缓存，避免重复调用。
4. 候选按以下顺序比较：
   - 是否消除长距离国道或明确硬风险；
   - 是否出现新的大货车、长隧道、危险桥梁、快速路或道路连续性问题；
   - 国道里程和未知道路里程变化；
   - 总里程、爬升、补给和住宿间隔；
   - 对 15 个骑行日及每日工作的影响；
   - 景观和 Vlog 内容价值。
5. 若平行小路更偏僻、补给更差、路况证据不足或风险转移而非降低，则保留原线并标记原因。

## 绕行预算与采纳规则

- 全程总绕行率不得超过 15%；当前 7.9% 为审查起点。
- 单个危险路段可以超过 15% 的局部绕行，只要全程仍不超过上限且 15 个骑行日仍然可行。
- 采纳候选至少需要满足：明显降低长距离国道或硬风险，并且没有引入更严重的新风险。
- 仅凭道路编号不能自动判断安全；省道、县道也必须检查连续性、补给、隧道和货车风险。
- 无法从数据确认的路段保留“需人工复核”，不得伪装成已经安全验证。

## API 使用顺序

1. 零点后先处理 5 个 P0 路段；
2. 再评估翁金线等基本顺路的景观候选；
3. 额度有余量时处理 P1；
4. 默认跳过 P2，除非资料发现硬风险；
5. 某段已经找到明显胜出的候选，或替代线连续更差时，立即停止继续穷举。

## 输出与验收

- 地图和分段数据明确区分：已采纳、已否决、需人工复核。
- 每个重点路段记录原线国道里程、候选道路名称、候选总里程、绕行率、风险依据和最终决定。
- 更新后全程绕行率不超过 15%，并重新验证最多 15 个骑行日。
- P0 每段必须有一个明确结论：采用替代线、保留原线并说明理由，或列为出发前人工复核。
- 最终决策面板保持简洁，优先展示会影响路线选择的结论，不展示无效的 API 探索过程。

## 非目标

- 不在本轮重新规划沿海线。
- 不追求避开所有国道编号道路。
- 不处理选车、上牌、磨合测试或维修训练。
