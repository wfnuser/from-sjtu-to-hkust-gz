# 上海市内前序路线设计

## 目标

把上海交通大学闵行校区之前的骑行打卡路线加入现有内陆完整版地图，形成一条连续主线：

1. 阳曲路
2. 昌化路649号
3. 京东上海（中海中心）职场
4. 阿里中心（虹桥）
5. 上海交通大学闵行校区
6. 原有上海交通大学闵行校区至香港科技大学（广州）路线

## 设计

- 新增前序点使用 `pre-01` 至 `pre-04`；上海交通大学及其后的 `main-01` 至 `main-27` 保持不变。
- 新增四个相邻路段，使用高德电助力路线 API 的真实道路折线；随后直接接入原 `main-01-to-main-02`。
- 原内陆路线的避国道候选、人工审核结论、路段 ID 和几何全部保留。
- POI 解析文件保存四个新地点经人工确认的高德候选，公开地图只包含坐标，不包含 API Key。
- 网页仍使用同一个默认内陆入口，不创建独立的“第一段地图”。

## 验收

- 默认地图从阳曲路开始，以香港科技大学（广州）结束。
- 上海交通大学闵行校区是连续主线中的第5个点，且原 `main-01-to-main-02` 及后续路段仍存在。
- 新增路段与原26个内陆路段共同出现在同一个 GeoJSON、summary 和 manifest 中。
- 既有6条避国道路线及9条审核决策继续引用原 `main-*` 路段。
- 完整测试、严格路线审计和浏览器加载验证通过。
