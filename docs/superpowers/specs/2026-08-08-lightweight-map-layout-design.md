# 轻量地图图例与等高侧栏设计

## 目标

降低道路图例的视觉重量，并让左侧路线信息在占满当前屏幕的独立滚动区域内展示，避免整个页面纵向溢出。

## 桌面布局

- 页面根容器、左侧栏和地图区域各自占满当前屏幕可视高度（CSS `100dvh`），不使用 JavaScript 测量或同步彼此高度。
- 页面本身隐藏纵向溢出；地图固定不随路线列表滚动。
- 左侧栏保留现有宽度，在栏内启用纵向滚动。
- 删除左侧栏现有的“大卡片式”道路图例。

## 轻量图例

- 图例作为地图右上角的常显浮层，不提供折叠按钮。
- 六类道路信息排成两列：骑行道、县道／旅游道路、省道、国道、需人工复核、可选支线。
- 使用紧凑短标签、小色线、半透明白色背景、细边框和轻阴影。
- 图例位于地图缩放控件的对侧，不遮挡主要操作控件；其层级高于地图道路图层。
- 浮层不拦截无关的地图拖拽区域，只在自身范围内占用点击区域。

## 小屏幕行为

- 小屏幕继续使用上下布局，不强行保留窄侧栏。
- 信息区和地图各自获得明确高度；信息区内部滚动，页面不因内容量而无限增高。
- 图例保持右上角，但缩为单列或更紧凑字号，以免超出地图宽度。

## 实现边界

- 只修改 `web/index.html` 和 `web/styles.css`；除非验证发现必要，不调整路线数据或地图渲染逻辑。
- 不增加第三方依赖。
- 不改变道路分类颜色、标签含义、路线统计或分段交互。

## 验收标准

1. 桌面窗口中，左侧栏和地图都占满当前屏幕，页面无纵向滚动条。
2. 左侧内容超过视口时，仅左侧栏出现滚动并可访问全部内容。
3. 六项图例在地图右上角常显，视觉体积明显小于原卡片。
4. 图例不遮挡左上角缩放控件，且不影响地图缩放、拖拽和分段定位。
5. 常见窄屏宽度下无横向溢出，地图与信息区仍可正常使用。
