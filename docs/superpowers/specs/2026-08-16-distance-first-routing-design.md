# 距离优先路线选择设计

日期：2026-08-16

## 目标

将执行路线从“尽量避开国道”改为“安全底线之上的距离优先”：不再仅为减少少量国道路程而明显绕行，同时保留对高速互通、匝道、收费站和货运道路的硬性规避。

Day 3 的执行目标为：杭州未来科技城海创园地铁站亚朵酒店 → 捷安特自行车（桐庐店）→ 富春江镇 → 麗枫酒店（杭州建德新安江店）。优先保留富春绿道南线的景观体验，并将全日路线控制在约 134–136 km。

## 选择规则

1. 先排除包含无法接受的硬风险或货运道路暴露的候选。
2. 在剩余候选中默认选择实际距离最短的路线。
3. 只有替代路线比最短路线最多增加 2 km，并且有道路级证据表明最短路线的国道路段缺少可靠非机动车通行空间时，才允许以减少国道暴露作为选择依据。
4. 国道本身不再构成自动绕行或审核阻断理由；是否采用平行道路取决于距离差和道路级证据。
5. 不因 API 将一段道路命名为互通就静默放行。若无法找到不超过 2 km 的已核验微绕线，该处保持未解决状态，不用十公里级绕行伪装成可执行方案。

## Day 3 路线设计

- 海创园亚朵 → 桐庐捷安特：采用约 73.3 km 的短候选，不再为了少 67 m 国道选择约 79.9 km 的候选。
- 桐庐捷安特 → 富春江镇：采用约 13.2 km 的候选，其中约 9.7 km 为富春绿道南线。
- 富春江镇 → 建德麗枫：以短线为基准，仅在新安江互通附近寻找不超过 2 km 的城市道路或绿道微绕线。
- 完全转入新安绿道南岸会额外增加约 10.6 km，不符合本设计的绕行上限，因此不采用。

## 代码与数据流

路线候选仍由高德骑行 API 提供。`route_planner/roads.py` 负责候选排序：先应用硬风险过滤，再执行距离优先和 2 km 近似路线规则。配置文件只为确有道路级证据的路段声明近似路线偏好，不再为普通国道路段设置“必须避开”的默认目标。

Day 3 的途经点、候选选择和人工微绕锚点写入执行路线配置；生成器重新生成 GeoJSON、manifest、summary 和 itinerary。网页移除“避国道”作为总体诉求的文案，只保留具体道路风险和可选方案的事实描述。

## 失败处理

- 找不到无硬风险且增量不超过 2 km 的微绕线：不自动退化到大绕行，也不删除风险证据；该局部段保持待核验。
- API 只返回含硬风险候选：生成流程不得将其标记为自动通过。
- 缺少“无可靠非机动车空间”的道路级证据：国道距离不得影响候选排序。

## 验证

- 单元测试覆盖：明显更短的国道候选应胜出；2 km 内且有明确证据的平行道路可胜出；硬风险和货运道路候选仍被排除。
